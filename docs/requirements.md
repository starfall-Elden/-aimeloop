# 需求与验收标准

整理日期：2026-10-05。以下从可读取的 AiMusic 相关聊天归纳；冲突和未定事项见 migration-notes.md。验收描述用于后续实施，不表示功能已完成。

## 定位与目标

AIMeloop 暂定为原创音乐社区，突出 AI 相关创作，同时接纳人工原创。目标用户为独立音乐创作者、AI 音乐创作者及听众。为学生非商业兴趣及大学申请项目，原目标三个月上线。成本要低，服务器必须位于美国、优先美西，并验证中国大陆用户的访问体验。

## MVP 功能

| 模块 | 需求 | 完成标准 |
|---|---|---|
| 账号 | 注册、登录、个人资料、语言偏好、账号状态 | 可注册登录；普通用户不能操作他人资料或管理后台 |
| 上传 | MP3、封面、歌曲资料及 AI 信息；上传权确认 | 文件规则生效，提交进入待审核；作者可查看状态和退回原因 |
| 播放 | 访客试听；固定底部播放器 | 播放、暂停、进度、音量、上一首/下一首可用；跨站内页面连续播放 |
| 作品与发现 | 作品详情、创作者主页、曲风/语言/创作类型筛选、搜索 | 仅审核通过且公开的作品可被访客发现；列表分页 |
| 互动 | 点赞、收藏、评论与回复 | 登录后互动；点赞收藏唯一；评论可审核与举报 |
| 排行 | 新歌、周榜、总榜、创作类型筛选；月榜范围待定 | 按有效事件和时间窗口计算，排除作者自己的播放及未公开作品 |
| 论坛 | 版块、主题、回复、置顶、关闭、本站作品卡片 | 登录后发帖回复；管理员可处理举报；首版不上传论坛附件 |
| 审核 | 作品人工审核、隐藏与恢复、账号管理、操作记录 | 审核权限独立；每次管理操作可追溯 |
| 规则 | 上传与社区规则、隐私、版权投诉与删除入口 | 用户能找到规则和投诉渠道，管理员能处理并留下记录 |
| 双语与适配 | 英文/简体中文、手机及电脑 | 首次语言选择正确，手动选择不会被自动覆盖，播放器不遮挡移动导航 |

## 上传规则

- 接受用户拥有上传与展示权利的原创作品；接受人工原创、AI 辅助、AI 生成并明确标注。
- 不接收翻唱、盗用伴奏或模仿真实歌手声音的作品；这是历史确定的平台规则。
- 首版只在线播放，不提供直接下载。
- 新用户每周最多上传 3 首；每首最长 10 分钟、最大 20MB；音频仅 MP3。
- 封面 JPG、PNG、WebP，最大 5MB。
- 字段包括歌名、创作者、简介、曲风、语言、创作类型、AI 工具与参与部分、作词/作曲/演唱者、上传权确认时间。
- 上传流程：文件和封面 → 歌曲与 AI 信息 → 权利确认 → 待审核 → 通过公开或退回修改。
- 待审核和退回作品仅作者与管理员可见；隐藏内容显示统一提示。
- 周配额的时区、自然周或滚动七天，以及修改/重提交是否计额，实施前明确。

## 语言规则

1. 已登录用户明确保存的语言偏好。
2. 浏览器中保存的手动选择。
3. Accept-Language；中文映射为简体中文，其余或无法识别时英文。
4. 无偏好时默认 en；中文代码 zh-hans。

提供 EN / 中文 切换，手动选择不被自动识别覆盖。不通过 IP 或国别推断语言。只翻译网站 UI、提示、规则和错误，作品、评论、论坛保持原文。URL 使用 /en/ 和 /zh-hans/ 前缀。新用户无明确选择时，语言字段应能表达“尚未选择”，避免默认 en 永远压过浏览器识别；具体模型实现见技术方案。

## UI 与页面

方向为简洁深色音乐界面：深蓝灰背景、深灰卡片、电光蓝主色，三类创作使用绿色/蓝色/紫色标签，标签同时带文字。参考成熟音乐平台的播放器、创作者信息与发现流程；不照搬品牌外观。首页不做大宣传横幅，最多约 20 首作品，论坛使用列表，管理后台采用 Django admin。

公开页面：首页、发现、排行、作品详情、创作者、论坛、搜索、关于、平台规则、隐私与版权。登录功能：上传、收藏库、互动、举报、账号与作品管理。建议路由为 /discover/、/charts/、/tracks/<id>/、/creators/<username>/、/upload/、/library/、/forum/、/forum/<category>/、/forum/topic/<id>/、/search/、/account/、/rules/、/privacy/、/copyright/，用户页面加语言前缀；后台 /admin/。

播放器包括封面歌名、播放暂停、上一首下一首、进度、音量、收藏。首版不做歌词滚动、音效调节或复杂队列。未登录互动时给出登录提示。

## 首版之外

在线 AI 音乐生成、付费会员/广告、私信、实时聊天、手机 App、复杂推荐、自动音频版权识别、大规模托管数据库及论坛附件。
